# In Motion Dance

Website solution for In Motion Dance, a family-run dance studio.

## Included
- Home page with original cartoon-style dance illustration
- Class information for ballet, jazz, hip-hop and adult beginner programs
- Editable timetable section
- About section
- Enrolment enquiry demonstration form
- Contact section
- Privacy notice
- Responsive design for mobile and desktop

## GitHub Pages
To publish the site, open this repository in GitHub and go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

The public address will be:
`https://plkanagu-dev.github.io/in-motion-dance-demo/`

## Privacy
The enquiry form in this demonstration does not transmit or store information. Do not place passwords, API keys, access tokens, or real student information in this repository.
